# Minova Cinema Desktop 1.0.8

This update makes Home recommendations substantially more varied by preventing the same leading movies from dominating multiple discovery shelves.

## Highlights

- Shares title-exposure information across New Releases, Top Picks for You, Top Rated, Hidden Gems, and Recently Added.
- Prioritizes titles that have not already appeared in an earlier discovery shelf.
- Gives Hidden Gems explicit priority over titles absent from Top Rated.
- Caps each curated discovery shelf at 24 titles instead of repeating an entire large library.
- Deduplicates and caps Watch Again and Watchlist shelves.
- Retains the custom Minova installer and automatic in-app updater introduced in 1.0.7.

Users on 1.0.0 need to install a newer build manually once because 1.0.0 did not contain the updater. Versions 1.0.2 and newer can discover and install this release from inside the app.
