# Minova Cinema Desktop 1.1.2

This picture update adds a selective Shadow Detail control for dark shows and movies while keeping the original presentation untouched by default.

## Highlights

- Adds **Shadow Detail** controls with Off, Low, Medium, and High levels directly in the native playback bar.
- Uses GPU shaders that lift near-black detail while preserving true black, color, midtones, and highlights.
- Saves one preference for an entire Plex show, so choosing a level once applies automatically to every episode.
- Keeps movie preferences title-specific so unrelated films retain their original picture.
- Composes Shadow Detail with the existing Balanced and ArtCNN enhancement modes instead of replacing them.
- Limits stored picture preferences to the 250 most recently configured shows and movies.
- Preserves the existing skip-intro/credits controls, 250% volume boost, mini-player, offline LAN support, updater, and branded installer.

Shadow Detail remains Off for every title until the viewer enables it. The setting can be changed or returned to Off at any time during playback.

Users on 1.0.0 need to install a newer build manually once because 1.0.0 did not contain the updater. Versions 1.0.2 and newer can discover and install this release from inside the app.
