# Minova Cinema Desktop 1.0.7

This release introduces a completely custom Minova Cinema installer for Windows, with separate experiences for first-time installation and updates.

## Highlights

- Replaces the standard Windows setup wizard with a frameless Minova Cinema interface.
- Automatically detects an existing installation and presents a dedicated update flow.
- Preserves the Plex connection, application preferences, and existing installation location during updates.
- Shows a clear “You're now up to date” confirmation after an update finishes.
- Keeps first-time installation options for the destination folder, desktop shortcut, and Start menu shortcut.
- Continues to support automatic in-app updates through a separate updater-compatible package.

Users on 1.0.0 need to install a newer build manually once because 1.0.0 did not contain the updater. Versions 1.0.2 and newer can discover and install this release from inside the app.
