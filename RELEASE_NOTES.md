# Minova Cinema Desktop 1.0.10

This update combines the proven stable interface with the new cinematic interface, letting you switch between them without giving up your Plex settings, playback features, or updater.

## Highlights

- Adds **Stable UI** and **Experimental UI** choices in Settings, with Stable UI remaining the default.
- Rebuilds the experimental Home, Movies, TV Shows, Collections, Watchlist, Search, library grids, details, seasons, episodes, cast, and playback surfaces as one coherent cinematic interface.
- Adds portrait discovery shelves, landscape Continue Watching cards, A–Z library browsing, genre filtering, and continuous or separated alphabetical layouts.
- Improves Continue Watching so completed movies and episodes are excluded and episode cards clearly identify their series.
- Makes personalized “Because you watched” shelves use meaningful similarity signals such as distinctive genres, themes, collections, cast, crew, media type, and release period.
- Prevents recommendation shelves from recycling the same leading titles across Top Picks, Top Rated, Hidden Gems, and personalized rows.
- Fixes season switching, episode navigation arrows, action-menu stacking, title typography, fixed-logo behavior, focus styling, and inconsistent shelf spacing.
- Keeps the existing Plex connection, preferences, playback engine, automatic updater, and branded installer shared across both interfaces.

Users on 1.0.0 need to install a newer build manually once because 1.0.0 did not contain the updater. Versions 1.0.2 and newer can discover and install this release from inside the app.
