# Minova Cinema Desktop 1.0.3

This release finishes the redesigned Windows experience while preserving the established Minova Cinema interface and Plex connection.

## Highlights

- Adds a resizable, draggable mini player with an optional always-on-top pin.
- Adds Plex artwork to movie and episode detail pages and keeps cast names visible.
- Replaces the standard frame with a clean Minova title bar and matching window controls.
- Adds an in-app update dialog with **Update** and **Not now** choices, download progress, and automatic restart after installation.
- Refreshes the Windows installer with Minova Cinema artwork and styling.
- Restores remembered Plex logins from earlier installations and retains current desktop preferences.
- Improves Plex connection errors with specific DNS, Tailscale, timeout, refused-connection, and TLS guidance.
- Keeps native libmpv playback, audio and subtitle track selection, Direct Play, and automatic HLS fallback.

Users on 1.0.0 need to install this release manually once because 1.0.0 did not contain the updater. Version 1.0.2 can discover and install this release from inside the app.
